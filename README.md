# Flock

A self-contained boids playground in your browser, inspired by [clainstone/cbirds](https://github.com/clainstone/cbirds) and Craig Reynolds’ boids.

**Website:** https://nicobrenner.github.io/flock/

This is an independent browser reimplementation, not the original C99 engine or an exact port.

## Play

Open `index.html` in a modern browser. No install, dependencies, build process, or server is required.

- Watch the automatic demo, or stop it to experiment.
- Adjust flock behavior, birds, hawks, colors, and shapes.
- Move your pointer to scatter birds; hold down to attract them.
- Try text formations, the live clock, trails, and depth effects.
- Pause, step through the simulation, save a PNG, or copy a link to your settings.

## GitHub Pages

Publish the `main` branch from `/ (root)` under **Settings → Pages → Deploy from a branch**. The `.nojekyll` file lets GitHub serve the static files directly.

To update the website, replace `index.html` and commit to `main`.
